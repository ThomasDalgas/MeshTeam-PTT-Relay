# Changelog

## 0.1.5 — 2026-10-20

First standalone public repository under the MIT license. Home Assistant repository packaging, Linux/Raspberry Pi Docker setup, Windows PowerShell and macOS/Linux shell helpers, native Node instructions, and cross-platform CI. Relay wire protocol remains v3.

## 0.1.4

Up to eight isolated groups on one server. A device can enroll separately in multiple groups. Per-group sockets, credentials, queues, telemetry and live-duration negotiation. HA group picker, group creation and scoped deletion. Existing single-group registries remain compatible.

## 0.1.3

MeshTeam PTT branding and logo; Danish, English and Romanian dashboard; names follow phone names; whole-group deletion; extended live speech on Android 71+. Short messages retain deferred delivery; long transmissions are live-only.
